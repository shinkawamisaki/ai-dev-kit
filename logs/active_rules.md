# 判例集（active_rules）— AI レビュアーが読む現在有効な判例

このファイルは AI レビュアーの `{{active_rules}}` に流し込まれ、**憲法（`.clinerules`）より
優先して**適用される。人間が下した判断のうち「いま有効なもの」だけを upsert で保つ
（同じトピックは上書きし、コンテキスト長を節約する）。

- 全履歴の証跡は [judgments.md](judgments.md) に append-only で残す（こちらは削除・編集禁止）。
- 新しい人間判断が出たら **両方を更新**し、対応するケースを `evals/cases/` に追加して
  回帰テストに固定化する（運用は [../evals/README.md](../evals/README.md)）。

> このファイルは PR の base コミットから読まれる（自己参照の遮断）。新規追加した判例は
> その PR 自身の審査には使われず、次の PR から有効になる。
